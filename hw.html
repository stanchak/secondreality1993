WHAT IT WANTED FROM YOUR PC

From README.1ST, 1993:

  processor  80386. “If your machine is 386-based, the demo will work,
             but many parts slow down and the demo simply looks worse.”
             A 486 and a fast VGA card were what they recommended.
  memory     570,000 bytes of free conventional memory — out of the
             655,360 DOS gave you, so a lean CONFIG.SYS was assumed
  EMS        1 MB, for Sound Blaster and SB Pro. None needed for the
             Gravis UltraSound, or with the sound switched off
  sound      SB, SB Pro, GUS — picked from a SETUP screen

It could also start from five places, which is where this board’s parts index gets the idea:

  SECOND    from the beginning     SECOND 3  the landscape scroller
  SECOND 2  the title screen       SECOND 4  the vector part
                                  SECOND 5  the end credits

And a Loop option, “for example at a computer exhibition”, which skips the end scroller and restarts after the credits. There is a sixth start point the README does not list — see /u.
